Passo a Passo para Contratar o Asura

1. Escolha o Serviço

Acesse o site do Asura e escolha o serviço desejado. O Asura oferece uma variedade de serviços, desde consultoria até desenvolvimento de projetos completos.

2. Crie um Pedido

Depois de escolher o serviço, siga as instruções para criar um pedido. Preencha os detalhes necessários, como prazo de entrega e detalhes do projeto.

3. Pague com USDC na Rede Base

Se preferir, você pode optar por pagar em USDC na rede Base. O contrato para esta opção é 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913. Para realizar o pagamento, siga os passos abaixo:

  • Acesse seu metamask ou outra carteira compatível com a rede Base.
  • Selecione a opção de enviar USDC.
  • Preencha o campo de endereço com 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913.
  • Insira a quantidade necessária de USDC.
  • Confirme a transação.

4. Pague com ETH (Rede Base ou Mainnet)

Caso prefira pagar com ETH, você pode escolher entre a rede Base ou a mainnet. O contrato para a rede Base é o mesmo do USDC, mas para a mainnet, o contrato é 0x3ecdD82B0abd76b4B32211d08eE309973760DF6F. Segue o passo a passo:

  • Acesse sua carteira compatível com ETH.
  • Cadastre-se ou entre com sua carteira.
  • Selecione a opção de enviar ETH.
  • Preencha o campo de endereço com 0x3ecdD82B0abd76b4B32211d08eE309973760DF6F para a mainnet ou 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913 para a rede Base.
  • Insira a quantidade necessária de ETH.
  • Confirme a transação.

5. Enviar o Hash da Transação

Após a transação ser confirmada, envie o hash da transação para o agente do Asura. O endereço da carteira do agente é 0x3ecdD82B0abd76b4B32211d08eE309973760DF6F. Você pode enviar o hash pelo site ou por e-mail.

6. Acompanhe a Entrega

Após a confirmação da transação, o Asura começará a trabalhar no seu pedido. Acompanhe o andamento do seu projeto pelo painel de controle do Asura ou por e-mail.
