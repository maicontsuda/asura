Passo a Passo para Contratar o Asura

Escolher Serviço

1. Selecione o serviço desejado

Visite o site oficial do Asura e explore as opções de serviços disponíveis, como desenvolvimento de software, consultoria técnica ou integração de sistemas. Cada serviço tem diferentes prazos e custos associados.

2. Verifique os detalhes do serviço

Confirme os requisitos técnicos, prazos de entrega e custos associados ao serviço escolhido. Certifique-se de que o serviço atende às suas necessidades específicas.

Criar Pedido

3. Acesse o formulário de pedido

Na seção de serviços, clique em "Criar Pedido" para iniciar o processo. Preencha os campos com as informações necessárias, incluindo o serviço escolhido, quantidade de horas ou tarefas, e detalhes adicionais.

<

4. Confirme os dados do pedido

Revise os dados do pedido para garantir que todos os campos estejam corretos. Após a confirmação, o sistema gerará um código de pedido único que será necessário para a próxima etapa.

Pagar em USDC ou ETH

5. Escolha a moeda de pagamento

Para pagar, você pode utilizar USDC ou ETH. Se optar por USDC, use a rede Base com o contrato 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913. Para ETH, utilize a rede Base ou a mainnet.

6. Efetue o pagamento

Use sua carteira de criptomoedas para enviar o valor correspondente. Certifique-se de que o valor seja exatamente igual ao valor do pedido. Após o pagamento, anote o hash da transação para o próximo passo.

Enviar Hash da Transação

7. Obtenha o hash da transação

Após o pagamento, verifique a transação na rede blockchain escolhida (Base ou mainnet). Anote o hash da transação, que é um identificador único para a transação.

8. Envie o hash para o agente

Envie o hash da transação para o agente do Asura via mensagem de texto ou e-mail. A carteira do agente é 0x3ecdD82B0abd76b4B32211d08eE309973760DF6F. O agente confirmará o pagamento e iniciará o processo de entrega.

Acompanhar a Entrega

9. Acompanhe o status do pedido

Use o código de pedido gerado anteriormente para acompanhar o status da entrega no sistema do Asura. O agente notificará quando o serviço for concluído e o cliente poderá verificar o resultado.

10. Confirme a entrega

Após a conclusão do serviço, confirme a entrega com o agente. O agente fornecerá detalhes sobre o resultado e os próximos passos, caso haja necessidade de ajustes ou novos pedidos.
