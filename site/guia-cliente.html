Como Contratar o Asura

Passo a passo para contratar o Asura com segurança e eficiência

1. Escolha o Serviço

Antes de iniciar o processo de contratação, identifique qual serviço você deseja utilizar com o Asura. Cada serviço pode ter requisitos específicos, como tipo de transação, valor e prazo de entrega.

Consulte a documentação do Asura para entender quais serviços estão disponíveis e quais são os requisitos técnicos.

2. Crie o Pedido

Após escolher o serviço, você precisa criar um pedido no sistema do Asura. Isso inclui fornecer detalhes sobre a transação, como o valor, o destino e as condições de entrega.

Confirme todos os dados antes de enviar o pedido para garantir que não haverá erros no processo.

<3>3. Pague com USDC ou ETH

Para realizar o pagamento, você pode escolher entre USDC ou ETH, conforme a rede que preferir:

  • USDC na rede Base: Contrato: 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913
  • ETH na rede Base: Use a carteira da rede Base
  • ETH na mainnet: Use uma carteira compatível com a rede Ethereum

Assegure-se de que a transação seja enviada corretamente e que a carteira tenha o saldo suficiente para o pagamento.

4. Envie o Hash da Transação

Após concluir o pagamento, envie o hash da transação para o agente do Asura. Isso é essencial para confirmar que o pagamento foi realizado e para iniciar o processo de entrega do serviço.

Use uma plataforma de rastreamento de transações para obter o hash da transação e garantir que ele esteja correto.

5. Acompanhe a Entrega

Com o hash da transação enviado, o Asura iniciará o processo de entrega do serviço. Você pode acompanhar o status do pedido no sistema do agente.

Se houver qualquer problema ou atraso, entre em contato com o agente para resolver o problema.
