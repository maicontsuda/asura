Garantias do Serviço

Nossa equipe se compromete a entregar um trabalho que atenda exatamente ao briefing fornecido. No entanto, se o entregável não atender às expectativas, trabalharemos para resolver o problema. Vamos detalhar o que acontece em cada situação:

Se o entregável não atender o briefing

Se o trabalho entregue não atender ao briefing fornecido, trabalharemos para corrigir o problema. Podemos realizar até três (3) ajustes gratuitos para que o resultado atenda às suas necessidades. Se os ajustes não resolverem o problema, discutiremos alternativas de resolução, que podem incluir uma reavaliação do projeto ou ajustes adicionais com custo adicional.

Quantos ajustes são permitidos

No nosso serviço, temos até três (3) ajustes gratuitos para corrigir problemas menores. A cada ajuste adicional, haverá um custo adicional, que será estipulado no momento da discussão das alternativas.

Prazo de resposta

Em caso de problemas ou dúvidas, responderemos a qualquer comunicação dentro de 24 horas. No entanto, para ajustes mais complexos, podemos precisar de até 7 dias úteis para implementar as mudanças.

O que não é coberto

Alguns aspectos não estão incluídos no serviço, como:

  • Revisões substanciais do briefing após o início do projeto.
  • Alterações significativas no escopo do projeto sem aviso prévio.
  • Testes de funcionalidade ou integração com outros sistemas não especificados no briefing.
  • Correções que não sejam tecnicamente possíveis com os recursos fornecidos.

Estas garantias e termos são para sua informação. No entanto, é importante verificar todos os detalhes com nossa equipe antes de iniciar qualquer projeto.
