Perguntas Frequentes - Asura

Como pagar com USDC na Base?

Para pagar com USDC na Base, você deve enviar o valor total do contrato para o endereço fornecido no contrato Asura. Certifique-se de que o endereço está correto e que a transação seja feita com o token USDC no network Base.

Como pagar com ETH na Base?

Para pagar com ETH na Base, envie o valor total do contrato para o endereço do contrato Asura. A transação deve ser feita com o token ETH no network Base, garantindo que o endereço esteja correto.

Como pagar com ETH na Mainnet?

Para pagar com ETH na Mainnet, envie o valor total do contrato para o endereço do contrato Asura. A transação deve ser feita com o token ETH no network Ethereum Mainnet, garantindo que o endereço esteja correto.

Como pagar com ETH na Base?

Para pagar com ETH na Base, envie o valor total do contrato para o endereço do contrato Asura. A transação deve ser feita com o token ETH no network Base, garantindo que o endereço esteja correto.

Quais são os prazos para o projeto?

Os prazos variam conforme o escopo do projeto. Após a confirmação do pagamento, o desenvolvimento começa imediatamente e o prazo é definido com base no tamanho da entrega. O prazo é comunicado no início do projeto e pode ser ajustado com antecedência.

O que acontece se o pagamento falhar?

Se o pagamento falhar, o contrato Asura não receberá a transação e, consequentemente, não iniciará o desenvolvimento do projeto. Nesse caso, o cliente deve revisar a transação e tentar novamente, garantindo que o endereço e o token estejam corretos. Caso persistam erros, entre em contato com a equipe para análise técnica.

Como recebo o entregável?

Após a conclusão do projeto, o entregável será liberado para você via endereço de contrato ou por meio de um repositório de código, dependendo do tipo de projeto. Você receberá um link ou um endereço para acessar o resultado final. Certifique-se de estar atento ao e-mail de notificação.

Qual é a identidade on-chain ERC-8004 #1149100?

A identidade on-chain ERC-8004 #1149100 é um identificador único associado ao contrato Asura. Ele é usado para rastrear a identidade do contrato no blockchain e garantir a autenticidade das transações. Esse número é essencial para verificar a legitimidade do contrato e para realizar transações seguras.

Como funciona o reembolso?

O reembolso é realizado em caso de cancelamento do projeto ou falha no cumprimento dos termos. Para solicitar o reembolso, entre em contato com a equipe e apresente o motivo. Caso a solicitação seja válida, o valor será reembolsado conforme os termos acordados, seguindo os protocolos do contrato Asura.
