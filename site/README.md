Como abrir o site

1. Localmente (navegador): abra o arquivo `index.html` no diretório `~/asura-site` com um navegador (arrastar e soltar ou File > Open).
2. Servindo por HTTP (recomendado para links relativos): abra um terminal no diretório `~/asura-site` e execute:

   python -m http.server 8000

   Em seguida, abra http://localhost:8000 no navegador.
