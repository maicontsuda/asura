Checklist de SEO Básico para Landing Pages

1. Título (Title)

  • O título deve ser curto, descrever o conteúdo e incluir palavras-chave relevantes.
  • Evite usar títulos longos ou repetitivos.
  • Exemplo: "Como aumentar suas vendas em 2024 – Guia Completo".

2. Meta Description

  • A meta description é o resumo do conteúdo da página.
  • Deve ter entre 155 e 160 caracteres e incluir palavras-chave.
  • Evite repetir o título e mantenha o tom persuasivo.

3. Headings (H1, H2, H3)

  • Use H1 para o título principal e H2/H3 para seções menores.
  • Evite usar H1 em mais de uma página.
  • Use palavras-chave em headings, mas mantenha a legibilidade.

4. Texto Alternativo (Alt Text)

  • Todo imagem deve ter um texto alternativo descritivo.
  • Evite usar palavras como "imagem" ou "foto" no alt text.
  • Use palavras-chave relevantes sem excesso.

5. Velocidade de Carregamento

  • Otimize imagens com ferramentas como TinyPNG ou ImageOptim.
  • Use formatos como WebP para imagens e SVG para ícones.
  • Evite scripts e CSS não essenciais no carregamento inicial.

6. Links Internos

  • Conecte páginas relevantes para melhorar a navegação e o SEO.
  • Use links internos para artigos, sobre nós e outros recursos.
  • Evite links quebrados e mantenha o conteúdo atualizado.

Evite: Texto duplicado, meta descriptions longas, imagens sem texto alternativo, links quebrados e conteúdos irrelevantes.

7. O Que NÃO Fazer

  • Não use palavras-chave de forma forçada ou a ponto de ser penalizado.
  • Não ignore o mobile-first, pois muitos usuários acessam por celular.
  • Não deixe o conteúdo vazio ou sem valor para o leitor.
  • Não ignore a experiência do usuário (UX) e o design responsivo.
