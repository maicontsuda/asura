Checklist de SEO Básico para Landing Page

1. Title Tag

  • Use um título curto e descritivo, com até 60 caracteres.
  • Inclua palavras-chave relevantes, mas não exagere.
  • Evite repetição e títulos genéricos como "Página Inicial" ou "Sobre Nós".

2. Meta Description

  • Escreva uma descrição única e atrativa, com até 160 caracteres.
  • Inclua palavras-chave e um chamado à ação (CTA).
  • Evite duplicar descrições em várias páginas.

3. Headings (H1, H2, H3)

  • O H1 deve ser único e representar o conteúdo da página.
  • Use H2 e H3 para organizar o conteúdo e facilitar a navegação.
  • Evite usar H1 em múltiplas seções ou em imagens.

4. Texto Alternativo (Alt Text)

  • Descreva claramente as imagens, vídeos e outros elementos visuais.
  • Use palavras-chave relevantes, mas sem repetição excessiva.
  • Evite deixar campos de alt em branco.

5. Velocidade de Carregamento

  • Optimize imagens com ferramentas como TinyPNG ou ImageOptim.
  • Use formatos como WebP para imagens e GIF animados.
  • Evite scripts e recursos desnecessários que aumentem o tempo de carregamento.

6. Links Internos

  • Conecte páginas relevantes dentro do site para melhorar a navegação.
  • Use links internos para direcionar o usuário para conteúdo relacionado.
  • Evite links internos que não agreguem valor ao conteúdo.
Evite: Títulos longos, descrições genéricas, H1 repetidos, imagens sem texto alternativo, páginas lentas, e links internos que não contribuam para a experiência do usuário.
