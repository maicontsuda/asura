Checklist de SEO Básico para Landing Page

1. Title Tag

  • Use um título único e relevante para cada página, com no máximo 60 caracteres.
  • Inclua palavras-chave principais e o nome da marca, se relevante.
  • Evite repetir títulos entre páginas.

2. Meta Description

  • Crie uma descrição única, atraente e com no máximo 160 caracteres.
  • Use palavras-chave naturais e inclua uma chamada para a ação.
  • Evite duplicar descrições entre páginas.

3. Headings (H1, H2, H3)

  • Use H1 apenas uma vez por página e para o título principal.
  • Use H2 e H3 para estruturar o conteúdo e melhorar a legibilidade.
  • Evite usar H1 em subseções para não confundir o motor de busca.

4. Texto Alternativo (Alt Text)

  • Descrição clara e concisa para cada imagem, com no máximo 155 caracteres.
  • Inclua palavras-chave relevantes, mas sem repetição excessiva.
  • Evite escrever apenas palavras-chave, o texto deve ser descritivo.

5. Velocidade de Carregamento

  • Optimize imagens com ferramentas como TinyPNG ou ImageOptim.
  • Use formatos de imagem modernos como WebP ou AVIF.
  • Reduza o uso de scripts e recursos externos que podem lentificar a página.

6. Links Internos

  • Conecte páginas relevantes da mesma site para melhorar a navegação e o SEO.
  • Use links internos para artigos, produtos ou páginas de contato.
  • Evite links quebrados ou que não levam a conteúdo relevante.

O que NÃO fazer

  • Não use palavras-chave de forma excessiva ou forçada (keyword stuffing).
  • Não inclua links quebrados ou não relevantes.
  • Não use meta tags duplicadas ou com conteúdo repetido.
  • Não ignore a experiência do usuário, pois o SEO também considera fatores de UX.
