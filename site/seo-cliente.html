Checklist de SEO Básico para Landing Page

1. Title Tag

  • Use um título claro e conciso que inclua palavras-chave relevantes. Exemplo: "Como Criar um Site Profissional em 7 Dias".
  • Evite títulos muito longos, mantendo no máximo 60 caracteres.
  • Evite repetir o mesmo título em várias páginas.

2. Meta Description

  • Cada página deve ter uma meta description única e atrativa, com até 160 caracteres.
  • Inclua palavras-chave e um chamado à ação, como "Saiba como..." ou "Descubra como...".
  • Evite repetição e use linguagem natural.

    • 3. Headings (H1, H2, H3)

    • O H1 deve ser usado apenas uma vez e conter o título da página.
    • Use H2 e H3 para organizar o conteúdo e facilitar a navegação.
    • Evite usar H1 em subseções ou em elementos como
      ou .

    4. Texto Alternativo (Alt)

    • Adicione descrições descritivas e únicas para cada imagem, com até 125 caracteres.
    • Evite usar palavras como "imagem" ou "foto" no texto alternativo.
    • Use palavras-chave relevantes, mas sem sobrecarregar.

    5. Velocidade de Carregamento

    • Optimize imagens com ferramentas como TinyPNG ou ImageOptim.
    • Use CDN para carregar recursos externos mais rápido.
    • Reduza o uso de scripts e CSS externos.
    • Evite usar plugins excessivos que podem afetar a performance.

    6. Links Internos

    • Conecte páginas relevantes dentro do site para melhorar a navegação e o SEO.
    • Use links semânticos e descreva o destino do link com clareza.
    • Evite links que não levam a conteúdo relevante.

    7. O Que NÃO Fazer

    • Não use palavras-chave de forma excessiva ou forçada (keyword stuffing).
    • Não repita o mesmo conteúdo em várias páginas.
    • Não use meta tags duplicadas ou inválidas.
    • Não ignore a experiência do usuário, pois ela afeta o SEO.
